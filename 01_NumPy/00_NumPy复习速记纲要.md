## 二、ndarray 本质（切记）

**ndarray = 数据区 + 数组头**
- 数据区：一整块**连续**内存，元素**同类型**
- 数组头（说明书）：`data 指针 + shape + strides + dtype`
- vs Python list：

| | list | ndarray |
|---|------|---------|
| 内存 | 分散（子列表各自独立） | 连续 |
| 类型 | 可混杂 | 必须统一 |
| 运算 | 手写循环 | 向量化，整体运算 |
| 速度 | 慢 | 快几十~百倍 |

- 维度语言：1 维=向量，2 维=矩阵，3 维+=张量
- C++ 对照：`int a[3][4]` 连续；`vector<vector<int>>` 不连续

## 五、索引与切片（高频）

### 索引方式对照（a 为 3×4）
| 写法 | 含义 | shape |
|------|------|-------|
| `a[0]` | 取第 0 行（降维） | `(4,)` |
| `a[[0]]` | 清单取行（保持二维） | `(1,4)` |
| `a[0,2]` | 第0行第2列元素 | 标量 |
| `a[[0,2]]` | 取第 0、2 行 | `(2,4)` |
| `a[[0,2,1]]` | 按 0,2,1 顺序取行（**花式索引=行号清单，非数据**） | `(3,4)` |
| `a[:,1]` | 所有行第 1 列 | `(3,)` |
| `a[0:2,1:3]` | 子矩阵 | `(2,2)` |

- 口诀：**逗号前管行、后管列；冒号全选；左闭右开；索引从 0 开始**
- 5×5 最大索引 = 4；`1:` 包含 1，`:1` 只含 0

### 布尔索引
- `a[a>80]`：先 `a>80` 得布尔掩码，再抽 True 元素，**结果恒为一维**
- 多条件：`(a>60)&(a<90)`，用 `& | ~`，**每条件加括号**
- `&`=逐元素逻辑（数组用）；`and`=整体布尔（数组会报错）
- 条件赋值：`a[a<60] = -1`（原地改）；顺序：算 mask → 定位 → 填充
- `np.where(cond, x, y)`：条件选择，返回新数组
- 不想改原数组：先 `.copy()`

## 七、内存模型（疑问集中区）

### 三种获取方式
```python
b = a          # 贴标签：同一对象，a is b = True
b = a.view()   # 新数组头、共享数据，is False
b = a.copy()   # 新数组头+新数据，完全独立
```

### strides = 地址字节偏移（非数值等差）
- 3×4 int64：strides=(32,8)
- 地址公式：`a[i,j] 地址 = base + i×32 + j×8`
- 转置：strides 交换 (8,32)，12 格地址一一对应，故数据不复制也能读全
- 切片视图：仅 base 偏移、strides 不变

### 视图/副本判定表
| 视图（共享 True） | 副本（独立 False） |
|------------------|-------------------|
| reshape、.T、切片、ravel、newaxis | copy、flatten、布尔索引、花式索引、np.sort |

- 花式索引**即使数字等差也是副本**（看形式不看规律）
- 不连续/乱序必须复制：固定步长公式描述不了忽前忽后的跳法

### 拿不准时三道保险
1. `np.shares_memory(a,b)` → True/False 直接给答案
2. 改 b 看 a 变不变
3. 要改子数组又想保护原数据 → 开头 `.copy()`

### 三维（2,3,4）
- 每固定一个索引消一维：`a[0]`→(3,4)，`a[0,0]`→(4,)，`a[0,0,0]`→标量 shape=`()`
- 整体筛选 `a[a>5]` 自动收集所有面成一维

## 八、细节切记（Q&A 凝练，每条一句）

1. `eye(3)` 的 1 在对角线 → 单位矩阵，默认 float 故带小数点
2. `size` 数格子（12），`nbytes` 才看浮点字节（96）
3. `zeros((3,4))` 双层括号：shape 是一个元组参数
4. `reshape` 不改原数组 → 必须 `x = x.reshape(...)`
5. `np.int32` 前缀正常，元素即该类型，无需强转（`int()` 可转）
6. `[x]` 单独出现=新建列表；`a[x]` 紧跟数组名=索引
7. `&` 优先级高于比较 → 条件必须加括号
8. 转置沿主对角线，对角元素不动
9. 标量 shape 是 `()`，不是 `(1,)`
10. 大数组打印省略中间：`np.set_printoptions(threshold=float('inf'))`
11. 对角线：`np.diag(a)` 或 `a[np.arange(n),np.arange(n)]`

## 九、拓展认知（讨论过，备查）

- **图存储**：邻接矩阵（稠密/矩阵运算）用 numpy；邻接表（变长邻居、刷算法题）用 list；超大规模稀疏图用 scipy.sparse(CSR)
- **set ≠ 并查集**：set 做静态集合运算，合并 O(n)；并查集管动态连通性，路径压缩+按秩合并，近似 O(1)，find/union 必须自己写
- Python 写算法：开发快、内置结构强；C++ 运行快；算法思想完全通用
- 列表字面量不会被解释器合并（可变对象），故 `[1,2] is [1,2]` = False
