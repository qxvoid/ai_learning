# Python 小项目说明

这些游戏用 Python **自带的 tkinter**（图形界面）和纯控制台写成，无需安装任何库。
目的：在 NumPy/Pandas 之外，找回写“纯 Python 逻辑”的手感，并接触 GUI 编程。

## 建议玩法（三步）

1. **先玩**：运行，玩通，知道它能做什么
2. **再读代码**：对照注释，弄清主循环、事件、数据结构怎么组织
3. **做改造**：完成下面的改造挑战，改出你自己的版本

运行：VSCode 打开 `.py` 文件点运行，或终端 `python 文件名.py`。

## 游戏清单

| 文件 | 类型 | 核心练习点 |
|---|---|---|
| 贪吃蛇.py | tkinter 图形 | 列表存蛇身、键盘事件、after 定时器、Canvas |
| 俄罗斯方块.py | tkinter 图形 | 二维列表、矩阵旋转、碰撞检测、消行计分 |
| 扫雷.py | tkinter 图形 | 二维列表、随机布雷、BFS 展开、左右键事件 |
| 猜数字.py | 控制台 | input、while、随机数、try/except 输入校验 |
| 文字冒险.py | 控制台 | **字典当邻接表**、集合背包、函数拆分 |

> 注意：文字冒险里的 `ROOMS` 字典，本质就是你 C++ 学过的图邻接表，
> 只是 Python 用字典写起来非常短。可以对照理解。

## 改造挑战（练手用，由易到难）

**贪吃蛇**
- 吃到食物后速度逐渐变快
- 撞墙后从对面穿出来（环形边界，类似生命游戏的 roll）
- 增加“特殊食物”，吃到加更多分且限时消失
- 记录历史最高分（写进一个 txt 文件）

**俄罗斯方块**
- 显示“下一个方块”预览
- 加等级系统：每消 10 行升一级、速度变快
- 方块落到底时有短暂停留可调整

**扫雷**
- 加难度选择（初级 9×9 / 中级 16×16 / 高级 16×30）
- 顶部显示剩余雷数和计时器
- 双击数字格时，若周围旗数等于数字则一键展开

**猜数字**
- 限定猜测次数，超过判负
- 结束后统计平均猜中次数
- 改成“电脑猜你想的数字”（二分思想）

**文字冒险**
- 加更多房间和物品（怪物、金币）
- 加血量和简单战斗
- 把房间地图从代码里挪到一个 JSON 文件读取

## 想继续深入 GUI
