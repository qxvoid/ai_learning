# 算法可视化与 AI 游戏

这个目录对应你说的"成就感项目"——把C++时代练过的搜索算法（BFS/A*/贪心）从console文字输出，
换成能用眼睛看的动画，回答"这些算法到底能用在哪"。

技术栈选 **Pygame**：调研时发现至少10个独立GitHub仓库在做"寻路可视化器"这个方向
（davepetrov/Pathfinding-Algo、sujal-goswami/Pathfinding-Visualizer、ArjunBalamwar/PathFinder等），
是个反复被验证、门槛适中又出效果的经典练手方向，不是随手起的点子。AI贪吃蛇同理，
Ta-Pc/AI-Snake-Game、dhillyon/snake-ai、hayderkharrufa/snake_pathfinding_ai 都是这个思路的独立实现。

## 项目清单

| 文件 | 内容 | 难度 |
|---|---|---|
| `01_寻路可视化器.py` | 网格地图，鼠标画墙，BFS/DFS/贪心/A* 逐帧点亮搜索过程，最后描出最短路径 | 入门 |
| `02_AI自动寻路贪吃蛇.py` | 贪吃蛇不再手动操作，每一步用BFS重新规划"到食物且不撞自己"的最短路径 | 进阶 |

## 玩法

```bash
pip install pygame   # 已经在 ai_learn 环境装好
python 01_寻路可视化器.py
python 02_AI自动寻路贪吃蛇.py
```

## 为什么这两个能给你"成就感"

C++时期的成就感来自"我知道这个算法能用在哪，能把它落地成一个能跑的东西"。
这两个项目算法逻辑几乎是直接从你脑子里搬过来的（BFS/A*的核心不用重写），
变的只是"壳"——从文字输出换成像素级动画。看得见搜索过程一层层扩散，
比在console里print一行"找到路径"更直观地证明你真的懂它在做什么。

## 延伸挑战（做完基础版之后）

**寻路可视化器**
- 加Dijkstra（带权重网格，比如"沼泽"格子走得更慢）
- 显示"已访问节点数"对比不同算法的效率差异
- 加迷宫自动生成（比如递归分割）

**AI贪吃蛇**
- 换成A*，对比和BFS找的路径是否一样
- 蛇变长后加"预测未来几步会不会把自己困死"的简单启发式
- 双人模式：一条蛇BFS、一条蛇A*，比谁先吃到食物
